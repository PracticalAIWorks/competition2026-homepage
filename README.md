# “提质增效、AI赋能”创新应用大赛门户

赛事门户原型，覆盖赛事介绍、赛程、项目设置、申报指引、通知公告、常见问题和独立的优秀作品展示页。

## 本地运行

无需安装第三方依赖，使用系统 Python 启动静态服务器：

```sh
npm run dev
```

浏览器访问 `http://localhost:4173`。

## 检查

```sh
npm test
```

该命令检查核心页面区域、响应式元信息、无障碍动效降级和页面文案标点约束。

## 目录

- `index.html`：页面结构与中文内容。
- `styles.css`：设计系统、响应式布局和动效。
- `app.js`：导航、数字动画、筛选、弹窗和申报演示交互。
- `showcase.html`：优秀作品展示页。
- `showcase-data.js`：已审核、脱敏且获授权的作品展示数据；初始为空，不展示虚构案例。
- `showcase.js`、`showcase.css`：作品筛选、空状态和展示页样式。
- `assets/`：赛事主视觉和案例图片等本地静态资源。
- `scripts/`：可重复执行的项目检查脚本。



当前图片为本地化的原型素材，正式部署前建议替换为内部审核通过的赛事主视觉与案例图片。

## 发布优秀作品

当前为静态站点：内容管理员完成授权、审核、脱敏和权限分级后，在 `showcase-data.js` 中新增作品记录并发布站点。在线上传、审批流、文件存储和受限资料访问控制需要接入后端与统一身份认证后实现。
